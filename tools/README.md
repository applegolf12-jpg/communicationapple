# 홈페이지 문의 접수 설정 (구글 시트 + 메일 알림)

1. applegolf12@gmail.com 계정으로 새 구글 시트 만들기 (이름: 홈페이지 문의)
2. 시트 메뉴 확장 프로그램 → Apps Script
3. 기존 코드를 지우고 `inquiry-apps-script.gs` 내용을 붙여넣고 저장
4. 함수 선택에서 `setup` 실행 → 권한 승인
5. 배포 → 새 배포 → 유형: 웹 앱 / 실행: 나 / 액세스 권한: 모든 사용자 → 배포
6. 나온 웹 앱 URL(…/exec)을 contact.html의 INQUIRY_URL에 넣기

코드를 고친 뒤에는 배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포 (URL 유지)
