# 홈페이지 접수 설정 (구글 시트 + 메일 알림)

- 행사 문의 → '홈페이지 문의' 시트의 '문의' 탭
- 아카데미 신청 → '홈페이지 아카데미 신청' 시트 (별도 파일, setup 실행 시 자동 생성)
- 알림 메일: applegolf12@gmail.com (코드 맨 위 NOTIFY_TO)

## 처음 설치
1. applegolf12@gmail.com 계정으로 새 구글 시트 만들기 (이름: 홈페이지 문의)
2. 확장 프로그램 → Apps Script → 기존 코드 지우고 `inquiry-apps-script.gs` 붙여넣고 저장
3. 함수 선택에서 `setup` 실행 → 권한 승인
4. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: 모든 사용자 → 배포
5. 웹 앱 URL(…/exec)을 사이트 코드의 URL_ 에 넣기

## 코드를 고친 뒤 (주소 유지)
1. 코드 붙여넣고 저장 → `setup` 한 번 실행
2. 배포 → **배포 관리** → 연필(수정) → 버전: **새 버전** → 배포
   (※ '새 배포'를 누르면 주소가 바뀌어 사이트 폼이 끊깁니다)
